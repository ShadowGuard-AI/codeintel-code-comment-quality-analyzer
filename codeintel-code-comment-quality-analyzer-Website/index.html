Functions, Classes, and Complex Blocks

codeintel-code-comment-quality-analyzer evaluates the quality and completeness of code comments. It checks for missing comments on functions, classes, and complex logic blocks, and enforces comment style consistency when a style guide is supplied. It uses AST analysis and pattern matching.

Style Only When a Guide Is Supplied

The style consistency check turns on only when a style guide is supplied. Without one, the watch is for missing comments alone.

A Demonstration, Not a General Detector

The README's own limit on its most ambitious claim, printed at full size because the file states that limit with unusual care: the outdated comment detection is a demonstration keyed to one example pattern, a line matching result = val + 5, with a nearby comment mentioning a word from that line; it does not read code changes, diffs, or version control history, and it does not detect outdated or misleading comments in general.

What a Run Actually Does
